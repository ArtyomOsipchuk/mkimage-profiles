# desktop-wallpapers

Скрипт выполняется на стадии создания образа. Он подменяет символьную ссылку на обои рабочего стола по умолчанию на заданный разработчиком.
Новая символьная ссылка `/usr/share/backgrounds/xfce/default-background` указывает на `/usr/share/backgrounds/xfce/xfce-leaves.svg`.
