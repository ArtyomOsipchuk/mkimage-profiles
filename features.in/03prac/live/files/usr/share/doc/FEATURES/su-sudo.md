# su-sudo

Скрипт выполняется на стадии создания образа. Во избежание использования прав администратора кем-либо кроме суперпользователя, был удалён пакет `sudo`. Например, после ввода пароля sudo админом, команда могла бы не запросить пароль в следующий раз. Чтобы действия администрирования были осуществимы, предложена альтернатива в виде команды `su`. Команда su подменяет окружение пользователя, что невозможно без ввода пароля администратора.
