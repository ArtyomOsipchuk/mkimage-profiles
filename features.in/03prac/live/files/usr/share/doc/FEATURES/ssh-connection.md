# ssh-connection

Скрипт выполняется на стадии создания образа. В образ подкладываются авторизованные ключи администраторов для подключения по ssh в отладочных целях. Также подкладываются `host keys` и выполняется команда `ssh-keygen -A`, что обеспечивает постоянный набор хост-ключей. Это позволяет избежать ошибки подсоединения при запоминании старых хост-ключей.
