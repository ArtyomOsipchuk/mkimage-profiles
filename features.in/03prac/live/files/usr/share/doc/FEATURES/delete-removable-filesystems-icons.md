# delete-removable-filesystems-icons

Скрипт выполняется на стадии создания образа. Он подкладывает конфигурационный файл xfce для рабочего стола `/etc/xdg/xfce4/xfconf/xfce-perchannel-xml`. В нём указано, что не нужно показывать не примонтированные файловые системы.
